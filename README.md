CartShare is a collaborative shopping cart web application that allows multiple users to create or join a room and manage a shared shopping cart.


- User login using mobile number
- Create and join rooms using a unique room code
- Room-based shared cart
- Add products to the cart
- Edit products
- Delete products
- Automatic total calculation
- Grand total
- Activity log for add, edit and delete actions
- Cart data persistence using localStorage
- Activity log persistence using localStorage
- Cross-tab cart synchronization
- Cross-tab activity log synchronization
- Responsive design for desktop and mobile
- Printable cart receipt
- Room code and participant information in receipt

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Browser localStorage

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `login.html` in a browser.
4. Enter a mobile number.
5. Create a new room or join an existing room using the room code.
6. Start adding products to the shared cart.
